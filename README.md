# Pix Tracker — demonstração

Dashboard demonstrativo para portfólio, construído com React, TypeScript, Vite, Tailwind CSS e shadcn/ui.

Esta versão funciona inteiramente no navegador com dados fictícios gerados localmente. Ela não possui autenticação, banco de dados, variáveis de ambiente ou conexão com Supabase.

## Executar localmente

```sh
npm install
npm run dev
```

## Verificações

```sh
npm run test
npm run build
```
